# User guide

[Project home](../../README.md) · [🇭🇺 Magyar](../hu/README.md)

VoidSentinel helps you see where a Windows application creates or changes files and folders. You choose the applications to watch, carry out a task in them, and review the recorded activity.

You can use it to find where a program saves its settings, check which folders an installer changes, or follow a document saved through a helper application.

## Before you begin

- Use Windows 11 x64.
- If you already have the built application, open `VoidSentinel.exe`. If you have the source code, follow [Build from source](build.md) first. After building, use `dist\VoidSentinel.exe`.
- Windows asks for administrator approval because monitoring uses Windows system events.
- **Start** begins a new recording. **Stop** ends recording and keeps its results available for review.
- Results stay in memory. Save anything you want to keep before selecting **Start** again or closing the app.
- Your application list and saved filter rules are remembered between runs.

The interface uses English labels. This guide uses the exact button and switch names so you can find them easily.
