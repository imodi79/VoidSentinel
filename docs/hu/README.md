# Felhasználói kézikönyv

[Projekt főoldala](../../README.md) · [English](../en/README.md)

A VoidSentinel megmutatja, hogy egy Windows-alkalmazás hol hoz létre vagy módosít fájlokat és mappákat. Kiválasztod a figyelendő alkalmazásokat, elvégzel bennük egy feladatot, majd áttekinted a rögzített tevékenységet.

Segítségével megkeresheted egy program beállításainak mentési helyét, ellenőrizheted a telepítő által módosított mappákat, vagy követheted egy segédalkalmazáson keresztül mentett dokumentum útját.

## Mielőtt elkezded

- Windows 11 x64 rendszert használj.
- Ha már megvan a lefordított alkalmazás, nyisd meg a `VoidSentinel.exe` fájlt. Ha a forráskódot töltötted le, először kövesd a [Fordítás forráskódból](build.md) útmutatót. Fordítás után a `dist\VoidSentinel.exe` fájlt használd.
- A Windows rendszergazdai jóváhagyást kér, mert a megfigyeléshez rendszereseményeket használunk.
- A **Start** új megfigyelést indít. A **Stop** befejezi a rögzítést, az eredmények pedig áttekinthetők maradnak.
- Az eredmények a memóriában élnek. A megtartandó adatokat mentsd el, mielőtt újra a **Start** gombra kattintasz vagy bezárod az alkalmazást.
- Az alkalmazáslistát és az elmentett szűrési szabályokat a program a következő indításra is megjegyzi.

A kezelőfelület angol nyelvű. A kézikönyv a gombok és kapcsolók pontos angol nevét használja, hogy könnyen megtaláld őket.
