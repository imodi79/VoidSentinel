# VoidSentinel 1.0.0

The first release of VoidSentinel: a Windows application that shows which files and folders your chosen applications change.

## Download and run

1. Download **VoidSentinel-1.0.0-windows-x64.zip** below.
2. Extract the ZIP into a folder of your choice.
3. Open **VoidSentinel.exe** and approve the Windows administrator prompt.
4. Add the applications you want to watch, select **Start**, and carry out a task in them.

**Requirements:** Windows 11 x64. The portable application includes its runtime and icons.

The standalone **VoidSentinel.exe** is also available as a separate download. **SHA256SUMS.txt** contains hashes for the EXE and ZIP.

## Features

- Watch one or more applications, including their child processes.
- Observe file and folder creation, writing, size and metadata changes, renames, and deletion requests.
- Review readable file summaries or switch to the full technical footprint.
- Count repeated operations in one entry and group activity by watched application.
- Follow observed rename destinations, including saves through temporary files.
- Edit persistent Include, Exclude, and Background rules; export and import them between computers.
- Export the current filtered results as CSV.
- Keep capture, filtering, sorting, and export work off the interface thread.
- Use the English interface with complete English and Hungarian user guides.

## Understanding the results

**Success** describes the result of an observed Windows request. A deletion request may complete before a file actually disappears. Temporary-file classification and process chains describe observed activity rather than user intent.

Capture results stay in memory until you save them as CSV. Save before starting another recording or closing the app. Filter rules and the watch list are remembered separately.

Check the **Lost** and **Dropped** counters when assessing completeness. Path aliases, folder renames, delayed system writes, and work delegated to independent services can limit attribution. The guides explain these cases and how to inspect the technical view.

## Validation

This release was checked with C++ unit tests, CSV and icon verification, and real Windows ETW integration tests covering parent/child activity, repeated writes, atomic-save renames, filtering, and the background session worker.
